#TimezoneClockReactTSRedux

Версия `React` 19.0.0. 
Версия `Node` 18.20.5. 
Версия `Webpack` - 5.97.1. 

Создание Часов с выбором города и часового пояса, используя `React`, `Redux`, `TS`, `Webpack`.

Для создания часов я использовал CSS. В том числе стрелки. Для анимации также CSS. 
Выбор обусловлен легкостью кастомизации и изменения объектов.

Для получения данных, я подключил `json-loader`, и написав API запрос подключил в код. Использовал `Axios`.

##Компоненты

`Clock.tsx` - Циферблат на котором через css и js установлены номера часов. А также логика по управлению часовыми поясами. Часовая стрелка в 2 раза меньше минутной.
`ClockPage.tsx` - Страница отображения списка циферблатов. А также:  Кнопка для управления циферблатами которых можно добавить от 1 до 10 показывая кол-во. И Кнопка `Удалить` последний добавленный. Каждый новый циферблат с новым часовым поясом.

##Development server
Для запуска сервера:

```cmd
npm run start
```
После запуска сервера откройте браузер и перейдите по адресу http://localhost:3000/.

##Building
Для сборки проекта выполните:

```cmd
npm run build
```
##Remote / Install
Чтобы создать клон репозитория в командной строке:

```cmd
git clone https://github.com/MoisGames/time-zone-clock-react-ts-redux.git
```

Чтобы запустить приложение: В терминале введите: 
```cmd
npm i
```

```cmd
npm run start
```
 Нажмите Enter
